# مِرآب | دليل زيوت السيارات

موقع عربي باتجاه RTL لعرض دليل أولي لأنواع سوائل السيارات اليابانية والصينية من 2005 إلى 2026. يمكن البحث باسم الشركة أو الموديل والتصفية بالشركة والسنة، ثم فتح بطاقة التفاصيل ومراجعة المصدر والتنبيه الخاص بكل سجل.

## التشغيل المحلي

```bash
pnpm install
pnpm dev
```

## فحص وبناء الإنتاج

```bash
pnpm run check
pnpm run build
```

يُبنى الموقع إلى مجلد `dist`. عند الدفع إلى فرع `main` ينفذ GitHub Actions الفحص والبناء ثم ينشر `dist` تلقائياً إلى GitHub Pages.

## حدود البيانات

الكتالوج الحالي دفعة أولية منظمة. لا تُستخدم أي كمية تعبئة غير موثقة؛ لذلك تظهر بعض السجلات بعبارة «غير محددة في السجل العام». يجب مطابقة سنة الصنع ورمز المحرك والناقل والسوق مع كتيب المالك قبل شراء الزيت أو تعبئته.
